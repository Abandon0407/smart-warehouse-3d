# 智能仓储温湿度监控系统 · 三维实时监控大屏

基于 STM32F103C8T6 + DHT11 + ESP8266-01S 的仓储环境监控系统，Web 端三维可视化大屏。

- 上半屏：控制板与仓储现场的三维模型，跟随 OneNET 云端数据实时联动
- 下半屏：温湿度实时值、趋势曲线、继电器控制、报警阈值

数据与手机 APP 同源（同一产品、同一设备、同一套物模型属性）。

## 在线访问

开启 GitHub Pages 后访问：`https://abandon0407.github.io/smart-warehouse-3d/`

## 硬件对应

| 通道 | 执行器 | 三维表现 |
|---|---|---|
| K1 | 通风风扇 | 扇叶加速旋转、气流线外射、冷蓝辉光 |
| K2 | PTC 陶瓷加热片 | 陶瓷芯转为橙红、热浪粒子上升、暖光 |

## 数据链路

```
DHT11 → STM32F103C8T6 → ESP8266-01S → MQTT → OneNET → 浏览器（5s 轮询）
```

页面为纯静态单文件，无后端依赖。
